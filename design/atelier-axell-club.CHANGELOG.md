# source/index.html — changelog

`source/index.html` is the source that generates the base shots
(`base/desktop.png` and `mobile.png`). It may change: prefixes
(`aac-` → `aa-`), contrast colours, and other exceptions. When it changes, the
base shots are regenerated from it, with the procedure in
`.claude/skills/axell-atelier-html-to-wordpress/scripts/shot-file-forced.mjs`
(reveals visible, transitions off), and this file records the change.

`atelier-axell-club-original.html` is the approved copy, kept unchanged. The
bases it generated are kept in `bootstrap/original/`.
